1. การสะท้อนของคลื่น (Reflection) & ผิวโค้งพาราโบลา ▼

1.1 กฎการสะท้อน (Laws of Reflection)

1. รังสีตกกระทบ เส้นปกติ (Normal line) และรังสีสะท้อน ต้องอยู่ในระนาบเดียวกัน

2. มุมตกกระทบ เท่ากับ มุมสะท้อนเสมอ (θi = θr) โดยวัดเทียบกับ เส้นปกติที่ตั้งฉากกับผิวสะท้อน เท่านั้น

1.2 ผิวสะท้อนรูปพาราโบลา (Parabolic Reflector) - จุดออกสอบบ่อย!

⭐ จำเป็นคู่ตรงข้าม:
• กรณีที่ 1 (จุดกำเนิดอยู่ที่จุดโฟกัส F): คลื่นสะท้อนจะเป็น "คลื่นหน้าตรง" (Plane wave) ขนานกับแกนมุขสำคัญ (เหมือนไฟหน้ารถยนต์หรือสปอตไลต์)
• กรณีที่ 2 (ส่งคลื่นหน้าตรงเข้าไปกระทบ): คลื่นสะท้อนจะเป็น "คลื่นวงกลมที่ลู่เข้าไปรวมกันที่จุดโฟกัส F" จากนั้นจะแผ่ขยายออกเป็นวงกลมต่อไป (เหมือนจานรับสัญญาณดาวเทียม)
ภาพจำลอง Interactive: การสะท้อนบนผิวโค้งพาราโบลา

1.3 การสะท้อนของคลื่นในเส้นเชือก

กรณี คลื่นสะท้อน คลื่นส่งผ่าน (ทะลุไป)
ปลายตรึงแน่น (Fixed end) กลับเฟส 180° (สันคลื่นสะท้อนเป็นท้องคลื่น) -
ปลายอิสระ (Free end) เฟสเดิม (สันคลื่นสะท้อนเป็นสันคลื่น) -
เชือกเล็ก → เชือกใหญ่ กลับเฟส 180° (รอยต่อเสมือนปลายตรึง) เฟสเดิมเสมอ! (สันคลื่นเป็นสันคลื่น)
เชือกใหญ่ → เชือกเล็ก เฟสเดิม (รอยต่อเสมือนปลายอิสระ) เฟสเดิมเสมอ! (สันคลื่นเป็นสันคลื่น)
2. การหักเหของคลื่นน้ำ (Refraction) & กฎของสเนลล์ ▼

2.1 กฎของสเนลล์ (Snell's Law)

สมการหลักของการหักเห:

sin(θ1) / sin(θ2) = v1 / v2 = λ1 / λ2 = n2 / n1
⚠️ ระวังจุดตกม้าตายอันดับ 1:
ความถี่ (f) คงที่เสมอ! ความถี่ขึ้นอยู่กับแหล่งกำเนิดเดิมเท่านั้น เมื่อคลื่นเคลื่อนที่เปลี่ยนตัวกลาง ความถี่จะไม่เปลี่ยนแปลงเด็ดขาด!

2.2 ตารางเปรียบเทียบ น้ำลึก vs น้ำตื้น

ปริมาณ บริเวณน้ำลึก (Deep Water) บริเวณน้ำตื้น (Shallow Water)
อัตราเร็ว (v) มาก (เร็ว) น้อย (ช้า)
ความยาวคลื่น (λ) ยาว (หน้าคลื่นห่างกัน) สั้น (หน้าคลื่นชิดกัน)
มุม (θ) มุมโต (กว้าง) มุมแคบ
ความถี่ (f) คงที่ คงที่
ทิศทางการเคลื่อนที่ น้ำตื้น → น้ำลึก: เบนออกจากเส้นปกติ น้ำลึก → น้ำตื้น: เบนเข้าหาเส้นปกติ
ภาพจำลอง Interactive: การหักเหของคลื่นผิวน้ำ (ลึก → ตื้น)
หน้าคลื่นในน้ำลึก (v มาก, λ กว้าง) → น้ำตื้น (v น้อย, λ แคบ, เบนเข้าหาเส้นปกติ)

2.3 มุมวิกฤตและการสะท้อนกลับหมด

• จะเกิดขึ้นได้เมื่อคลื่นเคลื่อนที่จาก บริเวณช้า → เร็ว เท่านั้น (ในคลื่นน้ำคือ น้ำตื้น → น้ำลึก)

• มุมวิกฤต (θc) คือมุมตกกระทบที่ทำให้มุมหักเหในน้ำลึกเป็น 90° พอดี (sin(θc) = vตื้น / vลึก = λตื้น / λลึก)

3. การเลี้ยวเบนของคลื่น (Diffraction) & หลักการฮอยเกนส์ ▼

3.1 หลักการของฮอยเกนส์ (Huygens' Principle)

“ทุกๆ จุดบนหน้าคลื่นสามารถทำหน้าที่เป็นแหล่งกำเนิดคลื่นจุดใหม่ (Wavelet) ซึ่งจะแผ่คลื่นหน้าวงกลมออกไปในทุกทิศทางด้วยอัตราเร็วและความถี่เดิม”

3.2 เงื่อนไขขนาดช่องเปิด (d) กับความยาวคลื่น (λ)

ขนาดช่องเปิด พฤติกรรมการเลี้ยวเบน ลวดลายคลื่นที่สังเกตได้
d ≤ λ (ช่องแคบ) เลี้ยวเบนสมบูรณ์เด่นชัดมาก แผ่ออกเป็น หน้าคลื่นวงกลม รอบทิศทาง และ ไม่เกิดแนวบัพ/การแทรกสอด
d > λ (ช่องกว้าง) เลี้ยวเบนไม่สมบูรณ์ ตรงกลางยังคงเป็น หน้าคลื่นตรง โค้งมนเฉพาะบริเวณขอบ และ เกิดแนวบัพ/ปฏิบัพ หลังช่อง
d >> λ (ช่องกว้างมากๆ) แทบไม่เกิดการเลี้ยวเบน คลื่นวิ่งเป็นลำตรงผ่านช่องเปิดไป ขอบโค้งมนเพียงเล็กน้อย
ภาพจำลอง Interactive: ปรับขนาดช่องเปิดเทียบกับความยาวคลื่น
d ≤ λ (เลี้ยวเบนหน้าวงกลมสมบูรณ์)
4. การแทรกสอดของคลื่นน้ำ (Water Wave Interference) ▼

4.1 แหล่งกำเนิดอาพันธ์ (Coherent Sources)

คือแหล่งกำเนิดคลื่นสองแหล่งที่มี ความถี่เท่ากัน และมี ผลต่างเฟสคงที่ (โดยปกติข้อสอบมักให้เฟสตรงกัน)

4.2 สูตรการแทรกสอด (เปรียบเทียบเฟสตรงกัน vs เฟสตรงข้ามกัน)

แนว แหล่งกำเนิด "เฟสตรงกัน" (In Phase) แหล่งกำเนิด "เฟสตรงข้ามกัน 180°" (Out of Phase)
แนวกลาง แนวปฏิบัพกลาง (A0) เสริมกัน แนวบัพกลาง (N0) หักล้างกัน!
แนวปฏิบัพ (Antinode / เสริมกัน) |S1P - S2P| = d sin(θ) = nλ
(n = 0, 1, 2, ...)		 |S1P - S2P| = d sin(θ) = (n - 0.5)λ
(n = 1, 2, 3, ...)
แนวบัพ (Node / หักล้างกัน) |S1P - S2P| = d sin(θ) = (n - 0.5)λ
(n = 1, 2, 3, ...)		 |S1P - S2P| = d sin(θ) = nλ
(n = 0, 1, 2, ...)
💡 สูตรหาจำนวนแนวทั้งหมดระหว่างแหล่งกำเนิด (ระยะห่าง d):
• หา nmax โดยแทน sin(90°) = 1:
- แนวปฏิบัพ (เฟสตรงกัน): n ≤ d / λ → จำนวนแนวทั้งหมด = 2(nmax) + 1
- แนวบัพ (เฟสตรงกัน): (n - 0.5) < d / λ → จำนวนแนวทั้งหมด = 2 × nmax
5. แสงเชิงคลื่น: สลิตคู่ของทอมัส ยัง (Young's Double-Slit) ▼

5.1 หลักการและลวดลาย

แสงสีเดียวผ่านสลิตคู่ S1, S2 ซึ่งทำหน้าที่เป็นแหล่งกำเนิดอาพันธ์ คลื่นแสงเดินทางไปซ้อนทับกันบนฉาก เกิดลวดลายแถบสว่างและแถบมืดที่ มีระยะห่างเท่าๆ กันทุกแถบ (Δy คงที่) และความสว่างค่อยๆ ลดลงอย่างช้าๆ

5.2 สูตรคำนวณสลิตคู่

แถบสว่าง (Bright Fringe / Antinode)
d sin(θ) = nλ หรือ d (yn / L) = nλ
n = 0 (แถบกลาง), n = 1, 2, 3, ...
แถบมืด (Dark Fringe / Node)
d sin(θ) = (n - 0.5)λ หรือ d (yn / L) = (n - 0.5)λ
n = 1 (มืดที่ 1), n = 2, 3, ...
สูตรระยะห่างระหว่างแถบสว่าง (หรือแถบมืด) ที่อยู่ติดกัน:
Δy = λL / d

• ถ้า λ มาก (แสงสีแดง) → Δy มาก (แถบอยู่ห่างกัน)
• ถ้า d แคบ → Δy มาก (แถบขยายกว้าง)
• ถ้า L มาก (ถอยฉากออกไป) → Δy มาก (แถบกว้างขึ้น)
• ถ้านำไปจุ่มในน้ำ (ดัชนีหักเห n): λ' = λ/n → Δy' = Δy / n (แถบชิดกันมากขึ้น)

6. แสงเชิงคลื่น: สลิตเดี่ยว (Single-Slit Diffraction) ▼

6.1 ข้อแตกต่างสำคัญระหว่างสลิตเดี่ยวกับสลิตคู่

⚠️ จุดที่ข้อสอบชอบหลอกเด็กที่สุดในประเทศไทย:
ในสลิตเดี่ยวกว้าง a สูตรหลักเป็นสูตรของ "แถบมืด (Dark Fringe)" ไม่ใช่แถบสว่าง!
a sin(θ) = nλ หรือ a (yn / L) = nλ (n = 1, 2, 3, ...)
(ห้ามใช้ n=0 เพราะ n=0 คือจุดกึ่งกลางของแถบสว่างกลาง!)

6.2 ความกว้างของแถบสว่างกลาง (Central Maximum)

• ขอบของแถบสว่างกลางถูกขนาบด้วย แถบมืดที่ 1 ทั้งสองข้าง (n = ±1)

• ระยะจากกึ่งกลางถึงแถบมืดที่ 1 คือ y1 = λL / a

• ดังนั้น ความกว้างของแถบสว่างกลาง = 2y1 = 2λL / a ซึ่ง กว้างเป็น 2 เท่า ของแถบสว่างข้างเคียงเสมอ!

• ความเข้มแสงของแถบสว่างกลางสูงมาก แถบสว่างข้างเคียงความเข้มแสงจะดรอปลงอย่างรวดเร็ว (เหลือเพียง ~4% ในแถบที่ 1)

7. แสงเชิงคลื่น: เกรตติง (Diffraction Grating) & การแยกสเปกตรัม ▼

7.1 สมบัติและสูตรการคำนวณ

เกรตติงประกอบด้วยช่องขนานขนาดเล็กจำนวนมาก (เช่น 100 - 10,000 เส้น/cm) ลวดลายที่ได้จะมีความคมชัดสูงมาก แถบสว่างแคบเป็นเส้นเล็กๆ และแถบมืดมืดสนิท

ระยะห่างระหว่างช่อง: d = 1 / N โดย N คือจำนวนเส้นต่อหน่วยความยาว
สูตรแถบสว่าง: d sin(θ) = nλ (n = 0, 1, 2, ...)

7.2 การกระจายแสงสีขาว (เกรตติง vs ปริซึม)

มิติเปรียบเทียบ เกรตติง (Diffraction Grating) ปริซึมแก้ว (Prism)
ปรากฏการณ์ การเลี้ยวเบน + แทรกสอด การหักเหของแสง (Refraction)
แถบสว่างกลาง (n=0) เป็นสีขาว (ทุกสีเบน θ = 0° เท่ากัน) ไม่มีแถบกลาง (แสงเบนไปทางฐานทั้งหมด)
สีที่เบนออกจากแนวกลางมากสุด แสงสีแดง (λ มากสุด ≈ 700 nm) แสงสีม่วง (f สูงสุด ดัชนีหักเห n สูงสุด)
สีที่เบนออกจากแนวกลางน้อยสุด แสงสีม่วง (λ สั้นสุด ≈ 400 nm) แสงสีแดง (ดัชนีหักเห n น้อยสุด)
เปรียบเทียบลวดลายความเข้มแสง: สลิตคู่ vs สลิตเดี่ยว vs เกรตติง
เกรตติงยอดแหลมคมชัด | สลิตคู่แถบกว้างเท่ากัน | สลิตเดี่ยวแถบกลางกว้าง 2 เท่า
8. ทวิภาวะคลื่น-อนุภาค (Wave-Particle Duality) & เทคนิคตอบอัตนัยเต็ม ▼

8.1 แสงเป็นคลื่นหรืออนุภาค?

แสงมีพฤติกรรมเป็น ทวิภาวะ (Wave-Particle Duality) โดยแสดงสมบัติดังนี้:

สมบัติความเป็นคลื่น (Wave Properties)
  • การแทรกสอด (Interference): สลิตคู่ของยัง แสงหักล้างกันจนมืดสนิทได้ (อนุภาคทำไม่ได้)
  • การเลี้ยวเบน (Diffraction): สลิตเดี่ยว แสงอ้อมขอบสิ่งกีดขวางไปตกในเงามืดได้
  • โพลาไรเซชัน (Polarization): แสงเป็นคลื่นตามขวาง กรองทิศทางการสั่นได้
สมบัติความเป็นอนุภาค (Particle Properties)
  • ปรากฏการณ์โฟโตอิเล็กทริก (Photoelectric Effect): แสงประพฤติตนเป็นก้อนพลังงาน (โฟตอน Photon) ชนอิเล็กตรอนหลุดทันที
  • ปรากฏการณ์คอมป์ตัน (Compton Scattering): โฟตอนชนอิเล็กตรอนแล้วถ่ายทอดโมเมนตัมเหมือนลูกบิลเลียด

8.2 โครงสร้างคำตอบข้อสอบอัตนัย 2-3 คะแนน (ตอบอย่างไรให้ได้คะแนนเต็ม)

📝 Checklist คีย์เวิร์ดที่ต้องเขียนลงในกระดาษคำตอบ:
1. เมื่อถามเรื่องสลิตคู่: ต้องมีคำว่า "แหล่งกำเนิดอาพันธ์", "ผลต่างทางเดิน (Path difference)", "แทรกสอดแบบเสริมกันเกิดแถบสว่าง", และ "แทรกสอดแบบหักล้างกันเกิดแถบมืด"
2. เมื่อถามเรื่องเกรตติงแยกสี: ต้องมีคำว่า "สมการ d sin(θ) = nλ", "มุมเบนแปรผันตรงกับความยาวคลื่น", และ "แสงสีแดงมีความยาวคลื่นมากกว่าแสงสีน้ำเงินจึงเบนมากกว่า"
3. เมื่อถามเรื่องแย้งอนุภาค: ต้องมีคำว่า "อนุภาคไม่สามารถแทรกสอดหักล้างกันจนหายไปได้" และ "อนุภาคไม่สามารถเลี้ยวเบนอ้อมสิ่งกีดขวางได้"

📐 รวมทุกสูตรที่ต้องใช้

1. คลื่นทั่วไป: v = fλ (f ไม่เปลี่ยนเมื่อเปลี่ยนตัวกลาง)

2. การหักเห: sin(θ1) / sin(θ2) = v1 / v2 = λ1 / λ2 = n2 / n1

3. แทรกสอดคลื่นน้ำ (เฟสตรงกัน):
• เสริม (A): |S1P - S2P| = d sin(θ) = nλ
• หักล้าง (N): |S1P - S2P| = d sin(θ) = (n - 0.5)λ

4. สลิตคู่ (ยัง):
• แถบสว่าง: d sin(θ) = d(y / L) = nλ
• แถบมืด: d sin(θ) = d(y / L) = (n - 0.5)λ
• ระยะห่างแถบติดกัน: Δy = λL / d (จุ่มน้ำ Δy' = Δy / n)

5. สลิตเดี่ยว:
• แถบมืด: a sin(θ) = a(y / L) = nλ (n = 1, 2, 3...)
• ความกว้างแถบสว่างกลาง: 2y1 = 2λL / a (กว้าง 2 เท่า)

6. เกรตติง:
• d = 1 / N | แถบสว่าง: d sin(θ) = nλ
• มุมเดียวกันซ้อนทับ: n1λ1 = n2λ2

⚠️ 10 จุดดักหลอกอันตรายที่สุดในข้อสอบ

  1. ความถี่ f คงที่เสมอ เมื่อคลื่นเปลี่ยนตัวกลาง แม้ความเร็วและความยาวคลื่นจะเปลี่ยน
  2. สลิตเดี่ยว a sin(θ) = nλ คือแถบมืด! ไม่ใช่แถบสว่างเหมือนสลิตคู่
  3. แหล่งกำเนิดเฟสตรงข้ามกัน แนวตรงกลางจะเป็น "แนวบัพ (N0)" ห้ามตอบปฏิบัพ
  4. เกรตติง แสงสีแดงเบนมากกว่าสีม่วง แต่ในปริซึม แสงสีม่วงจะเบนมากกว่าสีแดง (ตรงข้ามกัน!)
  5. แถบสว่างกลางของเกรตติง (n=0) เป็นสีขาว ไม่ได้แยกสีรุ้ง (แยกเฉพาะ n ≥ 1)
  6. ขยายช่องสลิตเดี่ยว (a กว้างขึ้น) แถบสว่างกลางจะ "แคบลง" ไม่ใช่กว้างขึ้น!
  7. เชือกเล็กชนเชือกใหญ่ คลื่นสะท้อนกลับเฟส 180° แต่ คลื่นส่งผ่านเฟสเดิมเสมอ
  8. การสะท้อนกลับหมด เกิดได้เฉพาะเมื่อคลื่นวิ่งจาก ช้า → เร็ว (น้ำตื้น → น้ำลึก)
  9. ระวังหน่วยเกรตติง: 600 เส้น/mm = 600 × 103 เส้น/m | 2,000 เส้น/cm = 2 × 105 เส้น/m
  10. โพลาไรเซชัน เป็นหลักฐานเดียวที่ยืนยันว่าแสงเป็น "คลื่นตามขวาง" (แทรกสอด/เลี้ยวเบนบอกแค่ว่าเป็นคลื่น)
