🔵 1. ชนิดของคลื่น & ความต่างเฟส

FOUNDATION
สูตรความต่างเฟส ($\Delta\phi$):
$$\Delta\phi = \frac{2\pi}{\lambda}\Delta x = \frac{2\pi}{T}\Delta t = \frac{360^\circ}{\lambda}\Delta x$$
  • เฟสตรงกัน: $\Delta x = n\lambda$ ($\Delta\phi = 2n\pi = 360^\circ, 720^\circ$)
  • เฟสตรงข้าม: $\Delta x = (n - 0.5)\lambda$ ($\Delta\phi = (2n-1)\pi = 180^\circ, 540^\circ$)

🟢 2. อัตราเร็วคลื่น & การสั่นของอนุภาค

CALCULATION
สมการหลัก & คลื่นในเส้นเชือก:
$$v = f\lambda = \frac{\lambda}{T} \quad \text{และ} \quad v_{เชือก} = \sqrt{\frac{T}{\mu}}$$

• $\mu = \frac{m}{L}$ คือ มวลต่อหนึ่งหน่วยความยาว ($\text{kg/m}$)
• ความเร็วสูงสุดของอนุภาค (SHM): $v_{p,\max} = \omega A = 2\pi f A$ (ระวังอย่าสับสนกับอัตราเร็วคลื่น $v$)

🟣 3. การสะท้อน, หักเห, แทรกสอด, เลี้ยวเบน

BEHAVIORS
กฎของสเนลล์ & การแทรกสอด:
$$\frac{\sin\theta_1}{\sin\theta_2} = \frac{v_1}{v_2} = \frac{\lambda_1}{\lambda_2} \quad (f \text{ คงที่})$$

• แทรกสอดเฟสตรงกัน: ปฏิบัพ $|S_1P - S_2P| = n\lambda$ | บัพ $|S_1P - S_2P| = (n-0.5)\lambda$
• แทรกสอดเฟสตรงข้าม: สลับสูตรทันที! แนวกลางเป็นบัพ $N_0$

🟠 4. คลื่นนิ่งในเส้นเชือก (Standing Waves)

HARMONICS
ความถี่ฮาร์มอนิกปลายตรึง 2 ข้าง:
$$L = n\frac{\lambda}{2} \implies f_n = n\frac{v}{2L} = n f_1$$

• ระยะ Node ถึง Node ติดกัน = $\frac{\lambda}{2}$ (1 Loop)
• ระยะ Node ถึง Antinode ติดกัน = $\frac{\lambda}{4}$
• โอเวอร์โทนที่ 1 = Harmonic 2 ($2f_1$), โอเวอร์โทนที่ 2 = Harmonic 3 ($3f_1$)

STUDY NOTE 📌

ทริคจำด่วน! หน้าห้องสอบชีวะ ม.5 💡

สรุปรวบยอด 3 วินาทีตอบได้ทันที

🌱 ปฏิกิริยาแสง (Light Reaction):

• ไม่เป็นวัฏจักร (Non-cyclic): วิ่งตรงเป็นเส้นยาว = ได้ครบจัดเต็ม! (ATP + NADPH + $O_2$) เกิดการแตกตัวของน้ำ Photolysis ที่ PSII
• เป็นวัฏจักร (Cyclic): วิ่งวนลูปที่ PSI = ได้แค่พลังงาน (ATP อย่างเดียว) ไม่มีน้ำแตกตัว!

🔄 วัฏจักรคัลวิน: "Car-Re-Re"

1. Carboxylation: ตรึง $CO_2$ กับ RuBP (5C) โดย Rubisco ได้ PGA (3C)
2. Reduction: ใช้ ATP + NADPH เปลี่ยนเป็นน้ำตาล G3P
3. Regeneration: ใช้ ATP สร้าง RuBP คืนชีพรอบใหม่!

🌵 พืช 3 แก๊ง ($C_3, C_4, CAM$):

• $C_3$ (พืชทั่วไป): ตรึง 1 ครั้งที่ Mesophyll อ่อนแอต่อความร้อน
• $C_4$ (ข้าวโพด อ้อย): ตรึง 2 "สถานที่" (Mesophyll $\to$ Bundle Sheath)
• CAM (สับปะรด กระบองเพชร): ตรึง 2 "เวลา" (เปิดปากใบเฉพาะกลางคืน $\to$ กลางวันปิดปากใบ)

1

การทดลองของนักวิทยาศาสตร์ในอดีต

  • • แวน เฮลมองท์ (Van Helmont): ปลูกต้นหลิว 5 ปี สรุปว่ามวลพืชที่เพิ่มขึ้นมาจาก "น้ำ" ไม่ใช่ดิน
  • • พริสต์ลีย์ (Priestley): พืชสีเขียว (หนู/เทียนไข/สะระแหน่) เปลี่ยน "อากาศเสีย" ให้เป็น "อากาศดี" ได้
  • • อิงเกนฮูซ (Ingenhousz): พืชจะฟอกอากาศได้ต้องใช้ "แสง" และต้องเป็น "ส่วนที่มีสีเขียว"
  • • เองเกลมันน์ (Engelmann): สรุปว่าพืชสังเคราะห์แสงได้ดีที่สุดใน "แสงสีน้ำเงินและสีแดง"
  • • แวน นีล (Van Niel): ศึกษาแบคทีเรียสีม่วง สรุปว่า $O_2$ จากการสังเคราะห์แสงมาจาก "น้ำ ($H_2O$)"
  • • โรบิน ฮิลล์ (Robin Hill): ปฏิกิริยาแสงผลิต $O_2$ ได้โดยไม่ต้องมี $CO_2$ ถ้ามีตัวรับอิเล็กตรอนที่เหมาะสม
2

กระบวนการสังเคราะห์ด้วยแสงของพืช $C_3$

  • • Light Reaction: เกิดที่ Thylakoid membrane ระบบแสง I (P700) และ ระบบแสง II (P680)
  • • Calvin Cycle: เกิดที่ Stroma ไม่ต้องใช้แสงโดยตรงแต่ต้องใช้ ATP และ NADPH จากปฏิกิริยาแสง
  • • ผลผลิตสุทธิ: ตรึง $CO_2$ 3 โมเลกุล ได้น้ำตาล G3P 1 โมเลกุล (ต้องหมุน 2 รอบ ได้กลูโคส 1 โมเลกุล)
3

โฟโตเรสไพเรชัน & เปรียบเทียบ $C_3, C_4, CAM$

  • • โฟโตเรสไพเรชัน: Rubisco เผลอไปจับกับ $O_2$ แทน $CO_2$ ในวันที่ร้อนจัด สูญเสียพลังงาน
  • • พืช $C_4$: แก้ปัญหาโดยตรึงคาร์บอน 2 ครั้งที่ Mesophyll (ใช้ PEP Carboxylase) แล้วส่งเข้า Bundle Sheath
  • • พืช CAM: แก้ปัญหาโดยเปิดปากใบตรึง $CO_2$ เฉพาะเวลากลางคืน เก็บไว้ในรูปกรดอินทรีย์ใน Vacuole
4

ปัจจัยที่มีผลต่ออัตราการสังเคราะห์ด้วยแสง

  • • ความเข้มแสง: อัตราจะสูงขึ้นจนถึงจุดอิ่มตัวแสง (Light Saturation Point)
  • • ความเข้มข้น $CO_2$: เพิ่มขึ้นจนถึงจุดอิ่มตัว $CO_2$ (พืช $C_4$ มีจุดอิ่มตัว $CO_2$ ต่ำกว่า $C_3$)
  • • อุณหภูมิ: มีผลต่อเอนไซม์ อุณหภูมิเหมาะสมที่สุดคือ Optimum Temperature (ถ้าสูงเกินไปเอนไซม์จะเสียสภาพ)
